# 3120 Change Part 보관실 · 3121 선별1실 통합 변경 검토서

| 항목 | 내용 |
| --- | --- |
| 대상 | 3120 Change Part 보관실 + 3121 선별1실 |
| 변경 내용 | 두 실 사이 벽체 철거 → 단일 실로 통합, 전체를 **선별1실**로 운영 |
| 라인 | 고형제 (비무균 경구고형제) |
| 청정등급 | Grade D 준용 (변경 전후 동일) |
| 제품 노출 | 있음 (정제 선별은 노출·분진 발생 공정) |
| 문서 상태 | 초안 — 실측치·자사 기준으로 확정 필요 |

---

## 1. 변경 사유와 방향

선별1실(3121)의 작업 면적 확보. 인접한 3120을 흡수하되 **change part 보관 기능은 통합 구역에서 완전히 제거**하고
비노출 구역(세척실 인접)으로 이설한다.

이 방향이 중요한 이유: change part를 그대로 둔 채 벽만 트는 안(案)은 아래 문제를 그대로 안는다.

- 선별 공정의 분진이 보관 부품 외포장·랙에 침착 → 타 제품 라인에서 개봉 시 교차오염 경로
- 해당 작업에 불필요한 자재의 상시 적치 → 라인클리어런스 요건과 충돌 (EU GMP 5.11)
- 세척필 상태(clean hold time)의 근거 약화, dirty/clean 동선 혼선

**보관 기능을 빼내는 현 방향에서는 위 세 건이 모두 소멸한다.** 잔여 과제는 시설 변경 자체의 관리로 한정된다.

## 2. 선결 조건

착공 전 아래가 확정·완료되어야 한다.

1. **Change part 보관처 이설 완료.** 세척실 인접 비노출 구역에 밀폐형 SUS 캐비닛 기준으로 확보.
   보관 조건(온습도·방충·세척필 식별·유효기한)이 현행과 동등 이상임을 확인.
2. 이설처의 보관 능력(수량·치수) 실사 확인. **이설 완료 전 벽체 철거 금지.**
3. 철거 대상 벽체가 **내력벽 / 방화구획선**에 해당하는지 구조·소방 검토.
   도면상 두 실 경계에 통과선(그리드 라인)이 있어 기둥열일 가능성 확인 필요.
4. 통합 후 실 번호 체계 확정 (3120 폐번 또는 3121로 통합 표기) — 실 표기가 들어가는 모든 문서에 영향.

## 3. 영향 평가

### 3.1 건축·마감

| 항목 | 검토 |
| --- | --- |
| 벽체 철거 | 내력/비내력 확인. 방화구획일 경우 대체 구획 또는 소방 변경신고 |
| 바닥 | 철거선 구간 마감 연속성. 이질 마감 접합부는 단차·크랙 없이 실링, 청소 가능한 표면 |
| 벽·천장 | 코빙(coving) 연속 처리, 조인트 실런트 GMP 적합 자재 |
| 도어 | 통합 후 복도측 도어 2개가 한 실에 잔존. **폐쇄하지 말고 인원 전용 / 자재 전용으로 분리 지정 권장** (동선 개선). 단 차압 유지를 위해 동시 개방 금지를 SOP에 명시 |
| 배수구 | 두 실에 표기된 심볼(배수구/감지기 등)의 정체를 전체 도면에서 확인. **노출 공정실 내 배수구는 원칙적으로 지양** — 존재 시 폐쇄 검토 |

### 3.2 HVAC — 가장 큰 변경 항목

- **급기 풍량 재계산.** 실 체적이 약 2배가 되므로 Grade D 환기횟수(통상 20회/h 이상, 자사 기준 확인) 유지를
  위해 급기량 재산정. 기존 두 실의 급기를 단순 합산하면 되는 경우가 대부분이나 **덕트·AHU 여유율 확인 필수.**
- **급기 사양 통일.** 첨부 도면상 3121의 급기 심볼(해칭 원)과 3120의 심볼(단순 원)의 표기가 달라 보인다.
  터미널 필터 사양이나 계통이 다르면 **선별실 기준으로 상향 통일**해야 한다. (도면 확대분 기준 판독이므로 원도면 확인 요)
- **차압 캐스케이드 재설정.** 통합 실 ↔ 복도 차압을 단일 기준으로 재설정. 도어 2개 구성에서의 차압 유지 확인.
- **기류 균일성.** 면적이 커지면서 정체 구역(dead zone)이 생길 수 있음 → 스모크 테스트로 확인.
- **국소배기.** 선별 작업대 증설 시 분진 포집 용량 재검토. 작업대 대수 증가분만큼 LEV 풍량 확보.
- 리턴/배기 그릴 위치가 통합 후 배치와 맞는지 확인 (한쪽에 몰리면 기류 편향).

### 3.3 전기·조명

- **조도가 핵심.** 선별은 육안검사 공정이므로 작업면 조도가 품질에 직결된다.
  통합으로 조명 배치가 바뀌면 **전 구역 작업면 조도 실측**이 필요하다.
  (일반적으로 육안 선별 작업면 500 lux 이상, 정밀 외관 선별은 1,000 lux 수준까지 요구 — 자사 기준 확인)
- 조도 균일도도 함께 확인. 구(舊) 3120 구역이 보관실 기준 조명이었다면 증설 필요 가능성이 높다.
- 콘센트·접지: 선별기 증설 시 전원 용량 확인.

### 3.4 소방·안전

- 스프링클러 헤드 살수 반경, 감지기 배치, 피난 거리 재검토
- 벽체 철거가 방화구획 변경에 해당하면 인허가 절차 선행

### 3.5 공정·동선

- 인원/자재/폐기물 동선도 개정. 도어 2개를 인원·자재로 분리 지정하는 안을 반영.
- 통합 실 내 **동시 취급 제품은 1품목으로 제한** (면적이 늘었다고 2품목 동시 선별을 허용하면 혼동 리스크가 새로 생김). SOP에 명시.
- 라인클리어런스 SOP: 대상 면적 확대에 맞춰 점검 범위·체크리스트 개정.

## 4. 위험 평가

| 1 | Change part 잔류 적치 | 이설 미완료 상태로 벽 철거 시 §1의 교차오염·혼동 리스크가 그대로 발생 | 이설 완료를 착공 선결조건으로 고정 | 낮음 |
| 2 | 환기횟수 부족 | 체적 증가 대비 급기 부족 → 청정도 미달, 분진 체류 | 풍량 재계산·재밸런싱, 재분류 시험으로 확인 | 낮음 |
| 3 | 기류 정체 구역 | 넓어진 실 일부에서 분진 체류 | 스모크 테스트, 필요 시 디퓨저 추가 | 낮음 |
| 4 | 차압 상실 | 도어 2개, 개방 빈도 증가 | 동시 개방 금지 SOP, 차압 연속 모니터링·알람 | 중간 |
| 5 | 조도 부족 | 구 3120 구역에서 선별 정확도 저하 → 외관불량 유출 | 전 구역 조도 실측, 부족 시 조명 증설 후 재측정 | 낮음 |
| 6 | 2품목 동시 선별 | 혼동(mix-up) | 1실 1품목 원칙 SOP 명시, 라인클리어런스 강화 | 낮음 |
| 7 | 공사 분진의 인접 운영구역 확산 | 인접 실 오염 | §6 공사 중 관리 적용 | 중간 |
| 8 | 마감 접합부 결함 | 청소 사각, 미생물·분진 축적 | 준공 검사 시 접합부 육안·실링 확인 | 낮음 |
| 9 | 청소 밸리데이션 범위 미반영 | 확대된 면적에 대한 청소 유효성 미입증 | 청소 SOP 개정 + 재밸리데이션 | 낮음 |

## 5. 적격성평가 / 밸리데이션 계획

변경관리(Change Control) 하에 아래를 수행한다.

**DQ** — 개정 배치도, HVAC 계산서, 조명 계산서, 실 사양서(URS/DS) 승인

**IQ** — 시공 도면 대비 실물 확인, 자재 성적서, 필터 설치·누설시험(설치 시), 도어·인터락, 계기 교정

**OQ / 재분류 시험** — 통합 실 전체 기준으로 신규 수행 (기존 두 실의 데이터는 승계 불가)

| 시험 | 비고 |
| --- | --- |
| 부유입자 재분류 | ISO 14644-1:2015. **면적 증가에 따라 최소 샘플링 지점 수 재산정**(표 A.1 / 근사적으로 √면적(m²) 올림). at rest 및 in operation |
| 부유균·낙하균·표면균 | 자사 Grade D 기준 적용 (비무균 고형제이므로 Annex 1은 법적 적용 대상이 아닌 준용 기준임을 문서에 명시) |
| 환기횟수 | 실측 풍량 기준 산출 |
| 차압 | 복도 대비, 도어 폐쇄/개방 조건 |
| 기류시험(스모크) | 정체 구역 확인 |
| 온·습도 | 선별 작업 조건 |
| 조도 | **전 구역 작업면 실측**, 균일도 포함 |
| 소음 | 작업환경 기준 |
| 청소(회복)시험 | 필요 시 |

**PQ / 청소 밸리데이션** — 확대 면적 기준 청소 SOP로 재수행. 환경모니터링(EM) 샘플링 포인트 재설정 후
초기 데이터 확보(통상 연속 배치 또는 정해진 기간).

## 6. 공사 중 관리

- 가설 칸막이로 공사구역 격리, 공사구역을 **음압**으로 유지하여 인접 운영구역으로의 분진 확산 차단
- 공사구역 담당 AHU 계통 격리 또는 해당 급배기 차단 (계통 공유 시 인접 실 영향 사전 평가)
- 인접 운영 실은 공사 기간 중 EM 강화 모니터링
- 자재 반입 동선을 운영 구역과 분리
- 준공 후 최종 청소·소독 → 재적격성평가 → 판정 완료 전 생산 사용 금지

## 7. 개정 대상 문서

- 실 배치도 / 청정등급도 / 차압도
- 인원·자재·폐기물 동선도
- Site Master File, VMP
- 실 환경관리 기준서 (차압·온습도·환기횟수)
- 환경모니터링 계획서 (샘플링 포인트·주기)
- 청소·소독 SOP (대상 면적·소요시간·약제량)
- 라인클리어런스 SOP / 체크리스트
- Change part 보관 SOP (이설처 반영, 보관·불출 동선 변경)
- 선별 작업 SOP (1실 1품목 원칙, 작업대 배치)
- 실 번호 체계가 인용된 배치기록서·점검표 일체

## 8. 완료 판정 기준

아래를 모두 만족할 때 변경 완료로 판정한다.

1. Change part 보관 기능 이설 완료 및 SOP 반영 확인
2. 재분류 시험 전 항목 기준 충족 (at rest / in operation)
3. 차압 기준 충족, 도어 개방 조건에서도 역류 없음
4. 전 구역 작업면 조도 기준 충족
5. 청소 밸리데이션 및 EM 초기 데이터 적합
6. 개정 문서 전건 승인·배포 완료, 관련 인원 교육 완료

## 9. 결론

Change part 보관 기능을 구역 밖으로 이설하고 통합 면적 전체를 선별1실 단일 용도로 사용하는 본 안은
**교차오염·혼동 측면에서 현행 대비 개선**이며, GMP상 수용 가능하다.

관리 포인트는 시설 변경 자체에 집중된다 — **HVAC 재밸런싱, 조도, 차압(도어 2개), 청소·EM 범위 확대**의 네 가지다.
이설 완료를 착공 선결조건으로 고정하고, 통합 실 기준의 재적격성평가를 완료한 뒤 생산에 사용한다.
