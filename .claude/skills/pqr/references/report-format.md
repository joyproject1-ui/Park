# PQR 보고서 서식 규칙 (기준 본에서 확정)

작성 기준 본은 **전년도 PQR 작성본**이다. 첨부 자료만 최신 파일로 갈아 끼운다.
아래 규칙은 나조린점안액(1회용) 기준 본(PQR26-5-NJSE2)을 판독해 확정한 것으로,
다른 제품에도 동일하게 적용한다.

## 머리글
- 문서번호: `PQR{작성년도 두 자리}-5-{제품코드}` (예: 2026년 작성 → PQR26-…).
  평가 대상 연도가 아니라 **작성 연도**를 쓴다.
- Rev. No. 는 언제나 `000`.
- 제품명 줄(`PQR{YY} {제품명}`)을 포함해 머리글 기입 값은 굴림 10.

## 글꼴 · 문단
- 본문 표준은 굴림 10. 표 안에 안 들어가면 10보다 작게 줄여도 된다.
- 표 머리행(항목 이름 행)은 굵게 + 회색 음영(E6E6E6).
- 최댓값·최솟값·평균·공정능력지수(Cpk)·Cpk 판정 결과 요약 행은
  라벨만이 아니라 **행 전체**를 음영 처리한다. 값은 굵게 하지 않는다.
- '특이사항 (Comment)' 라벨은 굵게, 그 아래 내용 줄은 기본 굵기.
- 4항·16항 같은 서술 문단은 2항 본문과 같은 줄간격 + 양쪽 맞춤.

## 사선 (마감 표시)
- 방향은 언제나 **왼쪽 아래 → 오른쪽 위** ("/", OOXML `w:tr2bl`). 반대 방향이
  남아 있으면 X 로 겹쳐 보이므로 지우고 긋는다 (`docx_form.close_out` 이 처리).
- 공양식의 빈 행(8.2.3, 11항, 14항, 15항)에는 **행 전체를 가로지르는 사선이
  그리기 개체로 이미 들어 있다**. 칸별 사선을 덧그리지 말 것. 이 행의 글자를
  지울 때는 run 을 지우면 그리기 개체까지 사라지므로 `w:t` 만 지운다.
- 여러 행이 같은 이유로 비면 세로 병합해 사선 하나만 긋는다
  (예: 7항 요약 3행의 비고, 10.x 비고 열 전체, 9.2 요약의 정성 항목).
- 값이 들어갈 칸과 기준(규격) 칸에는 절대 긋지 않는다.

## 표 배치
- 표가 페이지에서 잘리게 되면 다음 페이지 상단에서 시작한다. 행 단위로는
  절대 잘리지 않게 모든 행에 `cantSplit`.
- 9.2 세부 시험결과의 각 표는 페이지 상단에서 시작 (첫 행 첫 문단에
  `pageBreakBefore`). 반복 머리행(`tblHeader`)은 두 페이지에 걸치는 표
  (충전 기밀도·이물검사)에만 쓴다 — 그 외 표에 걸면 페이지가 밀릴 때
  이전 표의 머리행이 위에 남아 보인다.
- 페이지를 새로 시작하는 항: 1, 4, 6, 7, 8, 8.1.3, 8.2, 8.2.2, 9, 9.2,
  9.2.2, 9.2.3, ※Cpk 판정표, 10, 10.3, 11, 12, 13, 13.3, 14, 16.
- 페이지 나눔 제목 바로 앞의 빈 문단과 문서 끝의 빈 문단은 지운다 —
  공페이지의 원인이다.
- 목차 쪽수는 기준 본과 동일하게 채운다.

## 표 구조 (기준 본)
- 6항: 결과는 `■ 적합 □ 부적합` 한 줄(열 폭으로 보장), 비고 "/" 하나.
- 7항: 포장은 단일 열(내수/온누리 구분 없음), 기준 행에 사선 없음.
- 8.1.3: 부원료(KP)와 포장자재(자사규격)를 한 표에, 데이터 행 수만큼만.
- 8.2.x: 같은 원료는 No./원료 코드/원료명을 세로 병합. 8.2.1 은 원료별
  번호(1,2,3), 8.2.2 는 성적서별 번호(1..n)에 코드·이름만 전체 병합.
- 9.1: 공정 열 세로 병합, 질량·용량(평균/개개)·확인·함량·제제균일성은
  시험항목을 좌우 2칸으로 나눔, 이물검사는 자가) 2줄을 별도 행으로.
  포장 완료 후는 다음 페이지 별도 표(머리행 다시 표기), 각주는 충전 표 아래.
- 9.2.1: 성상·pH·비중·생균수 한 표 (바이오버든 별도 표 없음). 비중이 삭제된
  로트 구간은 세로 병합해 `1)` 하나만 쓰고 표 아래 각주.
- 9.2.2: ① 성상·질량용량(평균/개개)·pH ② 기밀도·이물검사.
- 9.2.3: ① 성상·확인(HPLC) ② pH·함량 ③ 불용성이물·불용성미립자·제제균일성
  ④ 무균·기밀도·포장규격 — 각각 한 페이지.
- 10.2~10.5: IQ/OQ/PQ 는 문서번호/완료일 2행 단위. IOQ 처럼 IQ=OQ 문서면
  가로 병합. PQ 없음이면 2행 세로 병합 후 사선 하나. 비고는 데이터 전 행
  세로 병합 + 사선 하나. IQ·OQ 는 기준 본 값 그대로, **PQ 만 최신
  마스터파일 값**으로 갱신.
- 12항: 변경사항은 CC 번호 + 무엇이 어떻게 바뀌었는지 알 수 있게 쓴다
  (예: "붕산 (EPB119) 제조원 추가", "반제품보관기간 변경(90 일→30 일)").
- 13.1: 포장 형태·보관 조건·실시 사유가 같으면 세로 병합.
- 13.3: 함량 (%) 은 공통 머리 칸으로 위에 두고 아래 행에 성분명.

## 빈 페이지를 만드는 세 가지 함정 (Word 에서만 나타남)

LibreOffice 로 변환해 확인하면 멀쩡한데 담당자 Word 에서는 빈 페이지가 생기는
일이 있었습니다. 원인은 셋이며, 모두 Word 만(또는 Word 가 더 엄격하게) 적용합니다.
그중 **0번이 가장 흔하고 가장 오래 못 찾은 원인**입니다.

0. **제목 문단 속에 숨은 하드 페이지 나눔** (`<w:br w:type="page"/>` run).
   공양식의 항 제목(4·6·8·10.2·10.3·11·12·13·13.3·16항)에 들어 있습니다.
   여기에 문단 속성 페이지 나눔(`pageBreakBefore`)까지 걸면 페이지가 두 번
   끊겨, 그 사이에 **문단 기호만 있는 빈 페이지**가 생깁니다. Word 화면에서
   빈 페이지에 ¶ 와 작은 ■(문단 서식 표시)만 보이면 이 경우입니다.
   → 하드 나눔 run 은 모두 지우고, 페이지 나눔은 `pageBreakBefore` 하나로
     통일합니다. 검사: 본문에 `w:br[@w:type='page']` 가 0개.

1. **표 셀 안의 페이지 나눔** (`w:pageBreakBefore` 가 `w:tc` 안 문단에 있는 경우).
   LibreOffice 는 무시하고 Word 는 적용합니다. 앞에 있는 제목 문단이 이미
   페이지를 열었다면 페이지가 한 번 더 끊겨 앞 페이지가 비어 버립니다.
   → 표를 새 페이지에서 시작시키려면 **표 앞에 페이지 나눔을 가진 빈 문단**을
     놓습니다 (사람이 Ctrl+Enter 를 누른 것과 같은 모양). `break_before_table()`.

2. **떠 있는 표** (`w:tblPr` 안의 `w:tblpPr` · `w:tblOverlap`).
   공양식에 섞여 있습니다. Word 는 이런 표를 본문과 따로 배치해서, 제목만 남고
   표가 다음 장으로 넘어가거나 빈 페이지가 생깁니다.
   → 만든 문서의 **모든 표에서 `tblpPr` · `tblOverlap` 을 지워** 본문 고정으로
     바꿉니다.

검사 방법 — 완성한 docx 에서 아래 넷이 모두 0 이어야 합니다.
하드 페이지 나눔 run 개수 · 셀 안 `pageBreakBefore` 개수 ·
`tblpPr` 를 가진 표 개수 · 표 바로 뒤의 페이지 나눔 없는 빈 문단 개수.

> LibreOffice 변환은 조판 확인용 보조 수단일 뿐입니다. 한글 글꼴이 없으면
> 대체 글꼴로 조판돼 쪽수가 실제와 달라지므로(굴림→NanumGothic 등),
> 쪽수는 담당자 Word 에서 확인받는 것이 최종입니다.

## 전년도 결재본이 .doc 일 때 — 변환 흔적 지우기

작성 기준 본이 옛 Word 파일(.doc)이면 편집을 위해 LibreOffice 로 .docx 로 바꿔야 하는데,
이때 담당자 Word 에서 **글꼴이 결재본과 달라 보이는** 흔적이 남습니다. 조판(표 위치·사선·
바닥글)은 그대로 옮겨지므로, 아래 넷만 되돌리면 결재본과 같아집니다.

1. **글꼴 이름에 세미콜론이 붙는다.** LibreOffice 는 `w:ascii="굴림;Gulim"` 처럼
   `이름;대체이름` 으로 씁니다. Word 는 이런 이름의 글꼴을 찾지 못해 다른 글꼴로 바꿔
   버립니다. → 모든 `w:ascii/w:hAnsi/w:eastAsia/w:cs` 값에서 `;` 앞부분만 남깁니다
   (앞부분이 깨진 글자면 뒷부분을 씁니다). `word/fontTable.xml` 의 `w:name` 도 같이 고칩니다.
2. **LibreOffice 대체 글꼴**이 섞여 들어옵니다. Liberation Serif → Times New Roman,
   Liberation Sans·FreeSans → Arial, WenQuanYi Zen Hei → 굴림 으로 바꿉니다.
3. **한글·숫자 자동 간격**(`autoSpaceDE`·`autoSpaceDN`)이 켜져 "품질보증 1 팀" 처럼
   벌어질 수 있습니다. → 둘 다 `false` 로 두고 `styles.xml` 의 `docDefaults` 에도 넣습니다.
4. **Strict OOXML 속성**(`w:jc val="start"/"end"`, `w:ind w:start/w:end`,
   `tblCellMar` 안의 `w:start/w:end`)을 Word 가 쓰는 `left/right` 로 되돌립니다.

검사 방법 — 완성한 docx 안 `word/*.xml` 에 `;` 가 든 글꼴 이름이 0 개여야 합니다.
조판이 결재본과 같은지는 원본 .doc 과 완성본을 각각 PDF 로 변환해 같은 쪽을 겹쳐 보면
확인됩니다(머리글의 문서번호·쪽수 말고 달라지는 곳이 없어야 합니다).
