# 절차서.docx — 18항 서식 채우기

빈 서식(절차서.docx)은 표 32개를 담고 있습니다. 표 번호는 `document.tables` 순서(0부터)입니다.
서식이 개정되면 번호가 밀리므로, **번호를 믿기 전에 표 머리글을 찍어 확인하세요.**

```python
from docx import Document
from docx.table import Table
d = Document('절차서.docx')
for i, t in enumerate(d.tables):
    print(i, len(t.rows), 'x', len(t.columns), '|',
          ' | '.join(c.text.strip()[:16] for c in t.rows[0].cells))
```

## 표마다 다른 병합 구조 — 여기서 대부분 틀립니다

### 9.2.x 세부 시험결과 (표 12–15)
`연번 | Lot No. | (시험항목 열 3~4개)` + 최댓값·최솟값·평균 행.
시험항목 이름은 **머리글 행에 직접 써 넣습니다**(서식은 비어 있음). Lot 행은 필요한 만큼 복제.

### 10.2–10.5 적격성평가 (표 18–21)
설비 **한 대가 두 행**입니다. 머리글 4행(완료일 / IQ·OQ·PQ / 문서번호 / 완료일)이 알려 주듯,
위 행에 IQ·OQ·PQ **문서번호**, 아래 행에 **완료일**을 씁니다.
`No.`·`관리번호`·`설비명`·`비고` 열은 두 행에 걸쳐 세로 병합(`vMerge`)되어 있으므로 **위 행에만**
쓰세요. 아래 행에 빈 문자열을 쓰면 위 행 내용이 지워집니다.
행을 늘릴 때도 두 행을 한 묶음으로 복제합니다.

### 7 수율현황표 (표 4)
머리글의 포장 하위 열은 `내수`=그리드 4, `외주`=그리드 5–6 인데, **데이터 행은 경계가 다릅니다**
— 첫 칸이 그리드 4–5 를 걸치고 둘째 칸이 그리드 6 입니다. 그래서 `내수`→열 4, `외주`→열 **6**
으로 써야 합니다. 열 5 에 쓰면 열 4 와 **같은 칸**이라 앞서 쓴 내수 값을 덮어쓰고, 외주가 빈 Lot
에서는 빈 값이 내수 값을 지워 버립니다.

원본 엑셀에서 대각선으로 마감된 칸(그 Lot 에 해당 없는 포장처)은 보고서에서도 `close_out()` 으로
같게 표시하세요. 빈칸으로 두면 "아직 안 적었다"로 읽힙니다.

### 채우기 전 충돌 점검 — 이 함정은 표마다 다릅니다
서식의 머리글 병합과 데이터 행 병합이 어긋난 표가 더 있을 수 있습니다. 값이 조용히 사라지는
사고를 막으려면 채우기 **전에** 한 번 확인하세요.

```python
from docx_form import colliding_columns
print(colliding_columns(table, 첫_데이터행, [0, 1, 2, 3, 4, 5, 6, 7]))
# [(4, 5)] 처럼 나오면 그 두 열은 같은 칸입니다 — 하나만 쓰고 다음 칸은 그 다음 열 번호로.
```

`최댓값·최솟값·평균` 행의 라벨(열 0–1 병합)과 `특이사항` 통합 행도 충돌로 잡히지만, 각각 한
칸에만 쓰므로 문제되지 않습니다.

### 13.3 안정성 경향분석 (표 27)
한 표에 **시험항목 3개**까지만 들어갑니다. 항목이 더 많으면 같은 표를 복제해 이어 붙이세요
(제목 문단도 같이 복제해야 표끼리 붙어 하나로 보이지 않습니다). 마지막 표에만 특이사항을 답니다.
행은 위에서부터 시험항목 / 안정성 종류·대상 Lot / 관리 규격 / 최소 / 최대 / 경향분석 결과.

### 특이사항 (Comment) 행
표 맨 아래 한 칸으로 병합된 행입니다. 첫 문단의 "특이사항 (Comment)" 라벨은 그대로 두고
그 **뒤에 문단을 추가**해 내용을 씁니다. `set_comment(table, *lines)` 가 이 일을 합니다.

## 통일문구 (PQR_통일문구.docx)

회사가 정해 둔 표준 문안이 있습니다. 서술을 새로 지어내지 말고 이 문안을 쓰세요 —
그래서 서술 생성에 Claude API 가 사실상 필요 없습니다. 자주 쓰는 것:

- **4항 일정** — "제품품질평가는 □□□□ 년 1월 ~ 12월까지 생산된 해당제품에 대하여 평가를
  실시하며, 'QC-126 제품품질평가 규정'에 따라 ■ 그룹으로 선정되어 ●●●●년도 ○분기 내에
  완료한다." (□□□□ 평가 년도 = 작성년도 직전 년도, ●●●● 작성 년도, ■ 그룹, ○ 분기)
- **11항** — 이력 없을 때 "평가 년도 내 중요 일탈 및 기준 일탈 이력 없음."
- **12항** — "품목허가(신고) 변경 관련 반려된 사항 검토 시, 특이사항 없음"
- **13항 보관조건** — 25±2℃/60±5%RH 로 보관한 반투과성 용기 제품은 ICH Q1A 2.2.7.3 수분손실률
  문구를 답니다. 불투과성 용기(알루미늄 튜브·유리 앰플)는 60%RH 가 정상이므로 쓰지 않습니다.
- **13항 차년도 완료** — "…시험 완료 일자가 ○○○○년이므로 차기 PQR에서 해당 결과 작성 및 검토 예정임."
- **14·15항** — "평가 년도 내 반품/불만/회수/시정조치사항 이력 없음."
  (14.1은 "점검기간 내 사용기한 경과로 인한 반품 외 특이사항 없음" 변형이 있습니다)
- **16항 결론** — "○○○에 대한 제품품질평가 결과, 출발물질, 포장자재, IPC Test 그리고 제품 시험
  결과 모두 정해진 규격에 만족하며, 기준에 적합한 제품이 일관되게 제조되고 있어 표준제조공정이
  적절하다고 판단됨. 이에 따라, 시정 및 예방조치 또는 재밸리데이션 진행 여부 검토 시, 해당되는
  사항은 없음을 확인하였음."

**주의**: "이력 없음" 문구는 **대장을 확인했을 때만** 씁니다. 자료를 못 받았으면 "자료 미확보"로
쓰고 무엇을 받아야 하는지 코멘트에 남기세요. 16항 결론도 미확보 항이 남아 있으면 확정하지 말고
단서를 답니다.
