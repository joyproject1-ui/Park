# 안정성 시험 경향 분석 결과 (HLF-QC-126-06)

`서식_HLFQC12606.xlsx` 는 **시험항목 하나당 시트 하나**입니다(pH, 삼투압, 함량, 유연물질 A·B·기타·총…).
시트마다 같은 좌표 구조에 차트가 하나 붙어 있습니다.

## 좌표

| 위치 | 내용 |
| --- | --- |
| `C3` | 제품명 |
| `G3` | 시험항목 (단위 포함, 예: `삼투압 (mOsmol/kg)`) |
| `C4` | 보관조건 |
| `H4` / `J4` | 하한관리기준(LCL) / 상한관리기준(UCL) |
| `M3` / `M4` | 작성자 / 작성일 — **기본은 빈칸**. 결재 전에 이름이 박혀 나가지 않게 두고, 담당자가 직접 적습니다 (담당자 2026-09-15: "작성자도 공란으로 작성해줘") |
| 36행 | `No.` · `제조 번호` · `시험 결과(Test Result)` 머리글 |
| 37행 | 시점 머리글 — `Initial` `3M` `6M` `9M` `12M` `18M` `24M` `36M` `48M` `60M` (C~L열) |
| 38행~ | 제조번호별 결과 |

한쪽 규격만 있는 항목(유연물질 등)은 LCL 칸이 비어 있습니다. 관리 규격을 표기할 때
`"%s 이하" % UCL` 로 씁니다. **비어 있는 기준 칸(H4·J4)은 그대로 두지 말고 사선을 긋습니다**
— 담당자 2026-09-15: "기준 공란인 경우는 사선처리 해줘." 결과 표와 같은 원칙(공란 없음)입니다.
엔진의 `_fill_sheet` 가 값이 없을 때 사선 서식을 넣습니다.

## 채울 때

- `openpyxl.load_workbook(path)` — 차트를 살리려면 `data_only=False` 로 열고 저장하세요.
  `data_only=True` 로 열어 저장하면 수식과 차트 참조가 날아갑니다. 값을 읽을 때만 별도로
  `data_only=True` 사본을 여세요.
- 정성 결과는 숫자로 바꾸지 말고 원문 그대로 씁니다 — `불검출`, `적합`.
- 최소/최대는 숫자 값만 모아 계산합니다. 전부 정성값이면 `불검출` 등으로 표기하세요.

## 공란 마감처리

시험하지 않은 시점 칸은 비워 두지 않고 **대각선으로 그어 마감**합니다(회사 관행).

```python
from openpyxl.styles import Border, Side
line = Side(style='thin')
cell.border = Border(diagonal=line, diagonalDown=True,
                     left=line, right=line, top=line, bottom=line)
```

대상은 **결과 표(38~49행)의 빈 칸 전부**입니다 — 시험 계획이 없는 시점, 아직 도래하지 않은
시점, 쓰지 않은 행(Lot 수보다 아래) 모두 긋습니다. 담당자 2026-09-14: "아래 엑셀표에서 공란은
사선처리 해줘, 해당 엑셀파일 전체에 반영". GMP 기록에 빈 칸을 남기지 않는다는 원칙입니다.
제조번호(B열)는 긋지 않습니다.

## 차트 범례

서식의 차트는 Lot 계열 6개 자리를 미리 잡아 두고 있습니다(미러 행 72~77). **자료가 없는
계열은 차트에서 지웁니다** — 남겨 두면 범례에 값 없는 색(주황 등)이 그대로 뜹니다
(담당자 2026-09-14: "범례표에서 해당 로트가 없는 경우는 삭제해줘"). 하한·상한 관리기준
계열(103·104행)은 언제나 남깁니다. 엔진의 `_rebuild_chart` 는 `lots[:ROWS]` 만큼만 계열을
만들므로 이미 이 규칙대로 동작합니다 — 손으로 만들 때만 주의하세요.
