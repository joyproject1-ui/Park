# 완성·승인된 PQR에서 확인한 작성 관행

승인된 최종본과 자동 생성 초안을 대조해 확인한 것들입니다. 서식만 봐서는 알 수 없고
틀리기 쉬운 부분이므로, 표를 채우기 전에 훑어보세요.

## 숫자 표기

**최댓값·최솟값·평균은 원자료와 같은 자릿수**로 적습니다. 평균에 자릿수를 하나 더 쓰고
싶어지지만(삼투압 303.67), 최종본은 `304` 로 적습니다 — 한 열 안에서 자릿수가 들쭉날쭉하지
않게 하려는 것입니다.

**반올림은 사사오입**입니다. 파이썬 기본 서식(`"%.3f"`)은 짝수 반올림이라 비중 평균
1.0165 를 `1.016` 으로 내지만 최종본은 `1.017` 입니다. `docx_form.summarize(values, 자릿수)`
가 두 규칙을 함께 처리합니다.

측정값 자체도 성적서에 인쇄된 표기를 그대로 옮깁니다 — pH 는 `7.00`(7.0 아님),
생균수는 `0`(0.0 아님). `docx_form` 과 함께 쓰는 `source_number()` 패턴을 참고하세요.

## 3. 대상 제품

| 항목 | 형식 |
| --- | --- |
| 제품분류 | `일반의약품` / `전문의약품` |
| 허가번호 | `제 0000 호` |
| 허가일자 | `2021년 01월 14일` |
| 제조/수입 여부 | `제조` (자사 제조여도 회사명을 쓰지 않습니다) |
| 사용기한 | `제조일로부터 24개월` |
| 보관조건 | `기밀용기, 실온(1~30℃)보관` — 허가상 보관조건이며 안정성 시험조건이 아닙니다 |
| 비고(제품명 행) | `주성분 : ○○○` |

## 6. 제조내역

- **제조단위는 배치 규모(L)** 입니다 — 성적서의 `LOT_수량`(관 수)이 아닙니다. 관 수를 적으면
  제조단위가 아니라 생산량이 됩니다. 제조지시서에서 가져오세요.
- 포장단위 표기: `0.5mL/관x30관`
- 결과 표기: `■ 적합 □ 부적합` (☑/☐ 가 아니라 채운 네모)
- 특이사항이 없으면 비고는 **비웁니다** — `N/A` 를 쓰지 않습니다.

## 9.1 시험결과표

- 허용기준마다 출처를 접두로 답니다: **`자가)`** 사내 기준 · **`허가)`** 허가사항.
  공정 중 시험은 대개 `자가)`, 완제품 시험은 `허가)` 입니다.
- **결과 열에 적합/부적합을 쓰지 않습니다.** 실제 값의 범위를 씁니다:
  `Av. 7.03(7.00 ~ 7.09)`, `0 CFU/100 mL`, 정성 항목은 판정 문장 그대로.
- 항목이 많으면 표를 나눕니다(공정 중 시험 + 완제품 기본 / 완제품 상세).
- 질량·용량처럼 기준이 둘인 항목은 `평균` · `개개` 하위 행으로 나눕니다.

## 9.2 세부 시험결과

- **성상은 `적합` 이 아니라 판정 문장 전문**을 씁니다 — `무색의 투명한 액`.
- 열 머리글에 단위를 넣습니다 — `삼투압(mOsm/kg)`, `바이오버든 (CFU/100mL)`.
  시험항목 이름도 성적서 표기가 아니라 보고서 표기를 씁니다(`생균수` → `바이오버든`).
- 한 표에 다 안 들어가면 항목을 갈라 표를 여러 개 만듭니다. 9.2.3 은 (성상·pH) /
  (질량·용량·기밀도·이물검사) 둘로, 9.2.4 는 넷으로 나뉩니다.
- 시험을 생략한 칸은 주석 번호(`1)`)만 남기고 표 아래에 사유를 답니다.

## 10. 밸리데이션

- 10.1 사유는 서술이 아니라 체크박스입니다: `□ 최초 □ 변경 ■ 정기적`.
  그 평가연도에 **완료된 것만** 적습니다 — 마스터에 있는 과거 이력을 전부 옮기지 않습니다.
- 10.2~10.5 는 **그 제품에 실제로 쓰는 설비만** 적습니다. 라인 설비 마스터 전체가 아닙니다.
  예: 주사용수만 쓰는 제품이면 10.4 에 정제수 계통을 넣지 않습니다.
- IQ·OQ 문서번호와 완료일도 채웁니다. PQ 만 담긴 마스터를 쓰고 있다면 IQ/OQ 는
  별도 적격성 대장에서 가져와야 합니다.

## 12. 변경관리

- 변경사항: `[CC-번호]변경내용 (변경 전 → 변경 후)`
- 조치사항: `- ` 로 시작하는 목록 (SOP 개정 · 변경통보서 · 제품표준서 개정 …)
- 적용Lot: **실제로 적용된 Lot 번호**를 씁니다 — "무균라인 생산 전 제품" 같은 범위 서술이
  아닙니다.

## 13. 안정성

- 13.2 시험기간은 날짜 범위가 아니라 **시점 표기**입니다 — `Initial` · `12M` · `24M`.
  비고에 `완료` / `진행중` 을 씁니다.
- 13.3 은 행이 Lot 별이 아니라 **`시판 후(연도)` 별 값의 범위**입니다 —
  `302 ~ 319`. 그 해에 여러 시점을 시험했으면 최소~최대로 묶습니다.
- 13.3 경향분석 결과 칸은 문장이 아니라 **`적합`** 한 단어입니다. 설명이 필요하면
  특이사항에 씁니다.

## 14 · 15 특이사항

이력이 없을 때만 통일문구의 "이력 없음"을 씁니다. **실제로 불만·반품이 있을 수 있으니
대장을 반드시 확인하세요** — 없을 것 같다는 짐작으로 "없음"을 쓰면 안 됩니다.
자료를 못 받았으면 "자료 미확보"입니다.
