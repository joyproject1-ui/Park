# 담당자 상시 지시 대장

한림제약 QA 담당자가 준 지시를 모아 둔 곳입니다. **모든 PQR 에 적용되는 규칙**이며,
한 번 말한 것은 다시 말하지 않아도 다음 제품부터 그대로 지켜야 합니다.

읽는 법 — **PQR 작업을 시작할 때 이 파일을 먼저 읽으세요.** 각 줄은 이렇게 되어 있습니다:

> **지시** (담당자 말) → **반영** (어떻게 지키는가) → `코드 위치`

새 지시를 받으면 **여기에 한 줄 더 적고** 코드에 반영하세요. 코드만 고치고 여기 안 적으면
다음 작업에서 왜 그렇게 하는지 알 수 없게 됩니다. 반대로 여기만 적고 코드에 없으면
지켜지지 않습니다 — 둘 다 해야 합니다.

---

## 0. 늘 지키는 것

| 지시 | 반영 |
|---|---|
| 실제 GMP 품질기록은 저장소에 커밋하지 않는다 | 산출물은 스크래치패드에 두고 파일로 전달. `docs/pqr/data.js`·`data.json` 은 .gitignore |
| 값을 지어내지 않는다 | 자료에 없으면 비워 두고 문의 목록에 남긴다 |
| 서명란(성명·서명일자)은 비운다 | 결재란은 채우지 않는다 |
| 파일 작성은 요청할 때만 | "작성해줘" 라고 할 때만 문서를 만든다 |

## 1. 자료를 읽는 규칙

| 지시 | 반영 | 코드 |
|---|---|---|
| 전년도 결재본은 장비·원료 등 **참고용**이고, 올해 자료로 새로 쓴다 | 해마다 바뀌지 않는 값만 빈 칸에 이어받는다 | `engine/carry.py` |
| 제조번호 셋째 글자가 제조 연도, PQR 은 그 다음 해 (OGY301 → 2025 제조 → 2026년 PQR) | 화면이 준 기간보다 제조번호를 앞세운다 | `engine/lotcode.py` |
| 모든 PQR 은 EDMS 공양식(E-HLF-32)으로 쓴다 — 평가항목 (v) 'PQR 작성 공양식' | 공양식을 바탕으로 쓰고, 없을 때만 전년도 결재본 | `engine/edms.py` |

## 3. 차림새 (모든 표·모든 항)

| 지시 | 반영 | 코드 |
|---|---|---|
| 표 크기는 **창에 자동으로 맞춤** — 모든 표 | 본문 폭에 맞춘다 | `layout.py` |
| 같은 원료·코드는 **셀 병합**. 원료코드 글씨가 잘리지 않게 | 세로 병합하고 열 폭을 넓힌다 | `docedit` |
| 내용이 없으면 **1행만 남기고 사선** | 빈 블록을 한 줄로 줄이고 가로지르는 선 | `docedit.collapse_empty_block` |
| **'확인 필요' 는 노랑 형광펜** | 그 글자에 형광을 칠한다 | `docedit.highlight` |
| 비고에 사선이 그어졌으면 **N/A 삭제** | 사선 칸의 N/A 를 지운다 | `docedit.drop_na_in_diag_cells` |
| 쓸데없는 엔터는 지운다 (각주 줄과 다음 작은 제목 사이) | 각주 뒤 빈 줄을 지운다 | `docedit.drop_blank_after_note` |
| 표 안 간격 조정 — '같은 스타일의 단락 사이에 공백 삽입 안 함' | `contextualSpacing` 을 켠다 | `docedit.zero_cell_spacing` |
| **1·3항 제목 줄맞춤** (번호 뒤 빈칸 통일) | 글자 자리로 찾아 그 런만 고친다 | `docedit.align_section_titles` |
| **16항 아래와 17항 시작부분은 한 칸 띄운다 — 모든 항이 마찬가지** | 항 제목 앞에 빈 줄 한 줄 | `docedit.space_before_sections` |
| 목차는 **점선 길이**를 페이지 번호 왼쪽에 맞춘다 | 목차 글자 크기를 줄이지 않는다 | `docedit.table_font_size(skip=목차)` |
| 페이지 번호(목차 쪽수)가 맞아야 한다 | 만든 자리에서 Word 로 필드를 다시 계산한다 | `engine/convert.refresh_fields` |

## 아직 담당자 확인이 필요한 것

- **13.1 시험 기간** — 평가 연도에 끝난 시점을 모두 적는다. 2026년 디겐타에서 OGX901 3M
  (2025.03.25 완료)을 넣을지 담당자에게 물었고 **넣으라**고 했다(2026-09). 한림 결재본에는
  빠져 있었다.
- **12항 '적용 Lot No.'** — 변경요청서에 어느 Lot 부터 적용인지 적혀 있지 않아 '확인 필요' 로 둔다.
- **손글씨 안정성 시험일지** — `ANTHROPIC_API_KEY` 가 있어야 자동 판독한다. 없으면 위 13항
  규칙대로 전년도 결재본에서 옮기고, 판독 결과(`13. 안정성시험일지 판독.json`)가 제품 폴더에
  있으면 그것을 먼저 쓴다.
