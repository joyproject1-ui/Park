    제작자 문의

    고치고 싶은 것을 말씀하세요

    이 프로그램은 한림제약 QA 담당자의 PQR 업무에 맞춰 만들었습니다. 화면·계산·서식 어느 것이든 바꿀 수 있습니다.

    고치고 싶을 때

    이 프로그램 안에는 대화창이 없습니다. 브라우저에서 claude.ai/code 로 들어가 이 프로그램을 만든 대화를 이어서 적으시면 됩니다.

    바꾸고 싶은 내용을 그대로 쓰시고, 화면을 캡처해 함께 올리면 더 정확합니다.

    예) "제품별 현황에 생산 Lot 수를 빼줘", "보고서에 시험자 이름도 넣어줘"

    고친 내용을 내 PC에 반영하려면

    프로그램 폴더의 PQR-업데이트.bat 을 더블클릭하세요. 최신 버전을 받아 프로그램만 바꿉니다 — 입력 폴더와 만들어 둔 보고서는 그대로 둡니다. 끝나면 PQR-대시보드-실행.bat 으로 다시 띄우면 됩니다.

    인터넷이 막혀 있으면 아래에서 ZIP 을 받아 손으로 덮어써도 됩니다.

    자주 막히는 것

    • 화면이 안 열립니다 — 검은 명령창을 닫으면 화면도 닫힙니다. PQR-대시보드-실행.bat 을 다시 실행하고 창은 켜 두세요.
    • 녹색불이 안 들어옵니다 — 자료 파일 이름이 보고서 항 번호로 시작해야 합니다 (예: 9.2.1 조제 완료 후.pdf). 파일은 제품 코드 폴더 안에 넣습니다.
    • 이력이 없는 항목 — 그 칸을 눌러 '이력 없음으로 마감'을 쓰면 확인 기록을 남기고 녹색으로 바뀝니다.
