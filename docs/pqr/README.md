# PQR 관리 대시보드

제품품질평가(Product Quality Review) 진행 상황을 한 화면에서 관리하는 UI 입니다.
외부 라이브러리 없이 단일 HTML 파일로 동작하며, 브라우저에서 `index.html` 을 바로 열면 됩니다.

## 실행 방법

**서버 모드 (자료 업로드 가능)**

```bash
python -m pqr serve --in <입력폴더>       # http://127.0.0.1:8787
```

평가항목 칸이나 자료 업로드 화면에서 파일을 올리면 제품 폴더에 저장되고 즉시 다시 집계됩니다.

**정적 모드 (보기 전용)**

```bash
python -m pqr build --in <입력폴더>       # 담당자가 올린 자료로 집계
cp out/dashboard/data.js docs/pqr/       # 대시보드에 연결
```

`index.html` 은 옆에 있는 `data.js`(`window.PQR_DATA`)를 먼저 찾고, 없으면 내장 샘플 데이터로
화면을 보여줍니다. 상단 오른쪽 📂 버튼으로 `data.json` 을 직접 열 수도 있습니다.
화면 오른쪽 위 표시가 `생성 데이터` 인지 `샘플 데이터` 인지 알려 줍니다.

입력 파일 형식과 계산 방법은 [`pqr/README.md`](../../pqr/README.md) 를 보세요.

## 화면 구성

| 화면 | 내용 |
| --- | --- |
| 대시보드 — 오늘 할 일 | KPI 6종, 단계별 PQR 분포, 마감 임박 목록 |
| 제품별 현황 / 내 담당 / 일탈·OOS / 일정 / 검토·승인 | 같은 표를 조건만 바꿔 보여주는 목록 화면 |
| 평가항목 자료 수집 | EU GMP Part I §1.10 (a)~(l) 항목별 수집 상태 매트릭스 |
| 품질 이슈 경향 | 최근 12개월 일탈 · OOS/OOT · 불만 추이 (차트 + 동일 데이터 표) |
| 지연 현황 · 리드타임 | 단계별 평균 소요일 대 내부 기준, 지연 사유 분포, 지연 목록 |
| 자료 업로드 | 제품 × 자료 종류 제출 표. 서버 모드에서 빠진 칸을 눌러 바로 올립니다 |

제품 코드를 누르면 우측 상세 패널에서 진행 단계, 미제출 자료, §1.10 항목별 상태를 볼 수 있습니다.

QA 파트별 워크플로우 · CAPA 유효성 · 평가 기준 · 보고서 생성 화면은
담을 내용만 적어 둔 설계 예정 화면입니다.

## 참고

- 샘플 모드에서 보이는 제품 · 배치 · 일탈 정보는 레이아웃 검토용 가상 데이터입니다.
- 평가항목 구성은 EudraLex Volume 4 Part I §1.10 (a)~(l) 을 따랐습니다.
